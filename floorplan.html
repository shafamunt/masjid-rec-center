Tennis lines (white, base court) Pickleball overlay 44 x 20 ft Volleyball overlay 60 x 30 ft Racquetball overlay 40 x 20 ft

How the shared court works: the court is built to full tennis size (78 x 36 ft). Pickleball, volleyball, and racquetball lines are painted on top in different colors. Only one sport plays at a time; a portable net is set up for whichever game is scheduled.

Footnote: a true racquetball court is an enclosed room with four walls and a ceiling. Per the project spec this court is lines-only on the shared outdoor court, which plays like outdoor racquetball/paddle games. A real enclosed racquetball court could be a phase-2 option inside the future building.
